# 진로 사운드스케이프 맵 — 초보자용 시작 파일

## 들어 있는 파일
- `index.html`: 웹페이지 구조
- `styles.css`: 색상과 화면 디자인
- `works.js`: **교사 승인 작품 목록** (주로 이 파일을 수정)
- `app.js`: 핀, 필터, 영상 팝업 기능
- `assets/illustrated-map.png`: 새로 제작한 고해상도 배경 일러스트 지도

## 1. 내 컴퓨터에서 먼저 열기
1. ZIP 파일을 압축 해제합니다.
2. `index.html` 파일을 더블 클릭해 브라우저에서 엽니다.
3. 예시 작품 핀과 작품 카드가 표시되는지 확인합니다.
4. 예시 작품은 영상 ID가 비어 있어 안내 문구가 표시됩니다.

## 2. 학생 제출 양식 만들기
Google Forms에서 다음 질문을 만듭니다.
- 작품 제목
- 진로 분야 (드롭다운)
- 작품 장소/상황 (예: 응급실, 베이커리, 방송 스튜디오)
- 작품 기획 의도
- 영상 링크
- 작품 공개 동의 확인 (학교 지침에 맞게 구성)

응답 탭에서 Google Sheets와 연결합니다. 응답 시트는 교사만 접근할 수 있도록 공유 권한을 확인하세요.

## 3. 교사 승인 후 공개하기
1. 제출된 영상과 설명, 저작권·개인정보를 확인합니다.
2. 공개할 작품만 `works.js`의 `works` 배열에 추가합니다.
3. 아래 예시 객체를 복사하고 내용을 바꿉니다.

```js
{
  id: "work-04",
  title: "빵이 구워지는 시간",
  career: "기타",
  place: "동네 베이커리",
  description: "제빵사의 작업 과정에서 들리는 소리를 관찰하고 구성한 작품입니다.",
  videoId: "여기에_유튜브_영상ID",
  x: 61,
  y: 53,
  icon: "♫"
}
```

- `id`: 작품마다 다른 식별자
- `title`: 공개할 작품명
- `career`: 필터 선택지와 정확히 일치해야 합니다.
- `place`: 지도에서 보여 줄 장소명
- `description`: 작품 설명
- `videoId`: 영상 주소의 ID 부분만 입력합니다. 예를 들어 `https://www.youtube.com/watch?v=abcdefghijk`라면 `abcdefghijk`입니다.
- `x`, `y`: 핀의 위치(0~100). x는 왼쪽에서 오른쪽, y는 위에서 아래로의 백분율입니다.
- `icon`: 핀 앞에 표시할 짧은 기호

## 4. Google Forms 주소 바꾸기
`index.html`에서 `YOUR_GOOGLE_FORM_URL`을 실제 학생 제출 양식 주소로 바꿉니다.

## 5. GitHub Pages로 공개하기
1. GitHub 계정으로 로그인하고 새 저장소(repository)를 만듭니다. 예: `career-soundscape`
2. 이 폴더 안의 파일과 `assets` 폴더를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. 배포 소스에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`를 선택하고 저장합니다.
6. Pages 설정 화면에 나타나는 주소로 접속합니다. 반영까지 몇 분 걸릴 수 있습니다.

## 운영상 중요한 점
- GitHub Pages에 게시한 파일은 공개될 수 있습니다. 학생 이름, 학번, 이메일, 얼굴, 위치 등 개인정보를 `works.js`나 사이트에 넣지 마세요.
- YouTube의 '일부 공개' 영상은 링크를 가진 사람이 볼 수 있으며, 링크가 재공유될 수 있습니다. 학교의 개인정보·저작권 지침과 보호자 동의 절차를 먼저 확인하세요.
- 학생이 제출한 작품이 자동으로 공개되는 구조가 아닙니다. `works.js`에 교사가 직접 추가한 작품만 공개됩니다.
- `works.js`를 수정하면 사이트에 반영됩니다. 승인되지 않은 작품은 이 파일에 넣지 마세요.
- 예시 데이터는 실제 학생 작품이 아닌 설명용 샘플입니다.


## 지도 관련 안내
현재 배경은 부천 원미구의 도심·공원·문화시설 분위기를 반영한 일러스트 콘셉트 지도입니다. 실제 도로망, 행정경계, 시설 위치를 정확히 재현한 공식 지도는 아니며 핀 위치도 상징적 위치입니다. 정확한 위치 기반 서비스가 필요하다면 공식 지도 또는 지도 API를 별도로 연동해야 합니다.
